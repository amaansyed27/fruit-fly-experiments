# Data attribution

This project uses **MaleCNS v1.0**, produced by the FlyEM Project at HHMI Janelia with the University of Cambridge, MRC Laboratory of Molecular Biology, and Google Research.

- Official dataset: https://male-cns.janelia.org/download/
- Dataset license: CC BY 4.0
- Supplemental optic-column assignments: https://github.com/flyconnectome/2025malecns

No MaleCNS data files are committed to this repository.

The implementation in this repository is independent. `fly.ai` / Fly64 and published Drosophila sensorimotor work were consulted as technical references for sparse-connectome simulation choices and candidate visual/descending populations; no third-party simulator source code is vendored here.
